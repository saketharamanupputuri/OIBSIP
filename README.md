# OASIS INFOBYTE SIP — Personal Portfolio Website

A beginner-friendly, responsive personal portfolio made with **HTML5, CSS3, and vanilla JavaScript**. It includes a home/hero section, about section, skills, featured projects, education/goals, contact form, mobile navigation, and a back-to-top button.

## Folder structure

```text
OIBSIP/
└── Web Development & Designing-Level 1-Personal Portfolio/
    ├── index.html
    ├── style.css
    ├── script.js
    └── README.md
```

For your actual submission, use the exact track/task naming format specified in your OASIS INFOBYTE task instructions. Keep all project files together inside the project folder in your public `OIBSIP` GitHub repository.

## How to run

1. Download or clone this project folder.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. For a more convenient development workflow, open the folder in Visual Studio Code and use the Live Server extension.
4. Edit the files, save, and refresh the browser to see your changes.

No build tools, package installation, or backend server are required.

## Personalize before submitting

Search the project files for these placeholders and replace them:

- `Your Name` — your actual name.
- `YN` — your initials for the decorative profile badge.
- `your.email@example.com` — your actual email address. Replace it in both `index.html` and `script.js`.
- `Your City, India` — your location, if you want to display it.
- GitHub and LinkedIn URLs — replace the generic profile links with your own profiles.
- About, education, skills, and project descriptions — make them accurate to your experience.
- Project cards — replace the example projects with work you have actually built. Do not claim example projects as completed work unless you have built them.

The skill bars are illustrative and should be adjusted to represent your actual skills.

## Features

- Responsive layout for desktop, tablet, and mobile.
- Mobile navigation menu with an accessible expanded state.
- Smooth section navigation.
- About, skills, projects, education/goals, and contact sections.
- Contact form validation and `mailto:` email preparation.
- Dynamic copyright year.
- Back-to-top button.
- Reduced-motion preference support.
- Semantic HTML and form labels.

## Important contact-form note

This is a static front-end website. The contact form does **not** store messages or send them to a server. It opens the visitor's default email application using `mailto:`. For a real production website, connect a backend or a trusted form service and add appropriate privacy and spam protection.
